# Test fixtures

Every file here is either copied verbatim from an external example or written by
hand in this repository. None of them is produced by the library's own codecs,
so a fixture never hides a codec defect by agreeing with it.

## Provenance

| Fixture | Origin | Role |
|---|---|---|
| `embrace/` | EMBRACE project example SSP, copied verbatim. `SystemStructure.ssd` declares the OMSimulator namespace (`xmlns:oms`), so it is tool-generated, not authored here. | Realistic multi-component SSD/SSP with 76 connectors, FMUs, an external `.ssv` binding and an `.ssm` mapping. |
| `embrace/resources/0001_ECS_HW/` | The extracted form of `embrace/resources/0001_ECS_HW.fmu` from the same example. | Source tree for the FMU archive fixtures; `tests/conftest.py` zips it on demand instead of keeping another binary. |
| `embrace/CONOPS.csv` | Part of the EMBRACE example. | Inert payload copied through archive round trips. |
| `mixed_example.ssd` | Hand-authored here (SSP1 `SystemStructureDescription` 1.0). | One system with an inline `ParameterValues` set and an unresolved external `source="external_values.ssv"` binding. |
| `external_values.ssv` | Hand-authored here (SSP1 `ParameterSet` 1.0). | External parameter source referenced by `mixed_example.ssd`. |
| `ssv2_ex.ssv` | Hand-authored here (SSP2 `ParameterSet` 2.0). | SSP2 parameter set with a 3x2 matrix parameter, arrays and several scalar types. |
| `test_schema_validation.srmd` | Third-party SRMD sample exported by easySSP (`generationTool`, `generationDateAndTime="2024-02-06T13:21:41Z"`), kept verbatim. | SRMD reference document for codec round trips and compliance checks. |
| `test.txt` | Arbitrary text written here. | Payload for `SSP.add_resource` and archive round-trip tests. |

No checksums are recorded: provenance plus the validation below is the contract.

## Regeneration and validation

Nothing here is generated by the library, so no fixture needs regenerating.
Validation is performed by the test suite itself:

- `python -m pytest tests/ -q` consumes every fixture above.
- `tests/ssp1/codec/test_ssd_xml_codec.py::test_mixed_fixture_is_hand_authored_and_schema_valid`
  validates `mixed_example.ssd` against
  `src/pyssp_standard/schema/SSP1/SystemStructureDescription.xsd`.
- `tests/ssp1/facade/test_srmd_ssp1.py::test_check_compliance_accepts_reference_fixture`
  runs the SRMD validator over `test_schema_validation.srmd`.
- `embrace/SystemStructure.ssd` is validated indirectly through
  `SSD.check_compliance()` in `tests/ssp1/facade/test_ssd.py`.
- Binary archive fixtures (`*.ssp`, `*.fmu`) are never committed or regenerated
  by hand: `tests/conftest.py` builds them in `tmp_path` from the directories
  above with `_write_zip_from_tree`.
